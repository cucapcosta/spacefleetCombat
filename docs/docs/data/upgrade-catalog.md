# Upgrade Catalog Reference

Upgrades are passive enhancements installed into ship upgrade slots. The number of available slots depends on ship classification.

## Upgrade Slots by Ship Class

| Classification | Upgrade Slots |
|---------------|--------------|
| Escort | 1 |
| Light Cruiser | 2 |
| Cruiser | 2-3 |
| Battlecruiser | 3 |
| Battleship | 4 |

## Defensive Upgrades

| Upgrade | Cost | Effect |
|---------|------|--------|
| **Additional Void Shield** | 30 | +1 shield capacity |
| **Auxiliary Shield Capacitor** | 20 | +1 shield regen per End Phase |
| **Belt Armour** | 25 | First subsystem critical hit is ignored |
| **Fire Suppression System** | 15 | 50% chance fires self-extinguish each turn |
| **Extra Turrets** | 15 | +2 turret rating (anti-torpedo) |
| **Reinforced Prow** | 20 | +1 prow armor value |

## Doctrines

Each ship has one doctrine slot for a faction-specific bonus.

### Imperial Navy Doctrines

| Doctrine | Cost | Effect |
|----------|------|--------|
| **Commissariat** | 15 | Ship cannot mutiny. Morale floor: 20. |
| **Mechanicus Rites** | 20 | +1 upgrade slot on this ship |
| **Space Marine Detachment** | 25 | +2 assault actions. Immune to enemy boarding. |
| **Navy Gunnery School** | 20 | +1 gunnery column shift on all batteries |
| **Torpedo Specialists** | 15 | +2 torpedo strength, -1 turn reload |
