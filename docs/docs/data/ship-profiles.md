# Ship Hull Reference

Ships are now **hulls with slots**. The hull defines innate stats and available weapon/upgrade slots. Actual weapons and upgrades are equipped separately. See [Ship Customization](/design/ship-customization) for the equipping system.

## Imperial Navy
